# Hard reversible synthesis: sparse rewards and start-state exposure

The preregistered sequence is in [PLAN.md](PLAN.md). The objective is to find a task where ordinary terminal-only RL cannot get a learning signal from the official start within a substantial matched budget, but random starts followed by specialization can. All three tasks use classical reversible gates, exact terminal equality, a small linear categorical policy, batch-centered REINFORCE and Adam; they are not LLM or neural proof experiments.

## Result: five-wire CNOT-only synthesis

Each state is an invertible binary 5×5 matrix (five row masks). The agent starts from identity and must realize target row masks `[20,23,26,28,4]` in at most nine CNOT gates. A legal gate XORs one row into another; every CNOT is its own inverse. The target was generated by a random nine-gate walk, then independently certified to require nine gates by disjoint radius-four BFS sets (22,531 states each). Exactly 2,596 optimal gate sequences exist; uniform random success from identity is 5.07e-9. The learner is *not* given the generating walk, the BFS, the shortest-path count, useful gates, distance, or a reference solution.

Native random starts apply one to four independently sampled legal CNOTs to the target, rejecting already-solved states. The target is unchanged and no label identifies the reset origin. The policy sees only the current five row masks in 5×32 one-hot representation. All arms use four seeds (42–45), 6,000 updates, 64 episodes per update, horizon nine, equal 3,456,000 padded policy action slots per run. The switch arm changes *only the reset distribution* after 1,000 updates. Each action reward is zero until exact target equality produces terminal success.

| Training condition | Training successes (all starts) | Training successes in ordinary phase | Final ordinary test | Exact root hit probability across seeds |
|---|---:|---:|---:|---:|
| Identity only | 0 / 1,536,000 | 0 | 0 / 2,048 | 4.70e-9–5.21e-9 |
| Random only | 1,387,536 / 1,536,000 | — | 0 / 2,048 | 2.87e-6–1.08e-4 |
| Random → identity | 1,086,032 / 1,536,000 | 929,995 | **2,044 / 2,048** | **99.8183–99.9490%** |

First ordinary-phase rewarded updates in the switched arm: 1356, 1320, 1587, 1010 (seeds 42–45). The ordinary-only policies were unchanged bit-for-bit. The final per-seed switched test counts were 509, 511, 512, 512 out of 512. A separate independent scalar replay verified **2,048/2,048 fresh switched-policy samples**, comparing outputs for all 32 input words, rather than using the training row-mask equality checker. The offline DAG audit also independently replays all 2,596 shortest sequences on all 32 inputs and computes exact final success probabilities.

Reset overhead: switched seeds each used 3.207–3.240M active training gate actions and 162,207–162,357 reset actions, totaling less than 3.456M ordinary baseline actions. Random-only used 1.287–1.354M active plus 0.973–0.975M reset actions; all have equal padded rollout/optimizer budgets. Evaluation and one-time offline certificate costs are separate. There are no claims of optimal runtime, generalization across tasks or models, or absolute inability of ordinary RL; this is one fixed task, one optimizer, one architecture, and a finite paired seed panel. Sampling from goal-local states deliberately changes starting difficulty and can be viewed as reverse-curriculum exposure; it does not change the task verifier. The result is exceptionally strong even though random-only barely transfers on its own.

## Boundary cases: reward access alone does not suffice

Both general reversible tasks tested before the CNOT pilot failed to transfer. These deliberately harder tasks count shortest paths exactly, eliminating arbitrary reward/horizon interpretations.

| Task | Uniform identity success | Ordinary training episodes across four seeds | Ordinary test | Exposure+specialization |
|---|---:|---:|---:|---|
| Four-wire generalized gates, exact ten, 39 paths | 3.464e-14 | 2,560,000 | 0/2,048 | All eight non-root arms zero root wins |
| Three-wire rare diameter-eight target, six paths | 1.395e-8 | 5,120,000 | 0/2,048 | All eight non-root arms zero root wins |

Four-wire: across four seeds, continuous native goal-walk length1..4 earned 2,086,012 successful training episodes, but exact root hit probabilities shrank to 1.54e-44–7.57e-36, vs unchanged ordinary 2.87e-14–4.38e-14. The 60%-switch version obtained 1,157,216 total successes and zero subsequent root training successes. Goal-walk1..8, mixed root/goal walks, and root-only perturbations did not fix it. Each run was 10,000 updates ×64 episodes ×10 slots, 6.4M padded slots. Four-wire offline certificate verified a disjoint radius-five root and radius-four goal map (5,119,080 and 311,528 states), with a ten-step witness; all 39 shortest sequences were independently scalar-replayed and audited.

Three-wire: the mechanically selected diameter target (`[7,3,6,1,5,4,2,0]`) had six shortest action sequences versus 622 in the earlier panel. Continuous goal-walk1..4 generated 5,054,583 successes in 5.12M training episodes yet reduced root probability from 1.30e-8–1.56e-8 to 3.50e-31–5.63e-28. Switches at 180, 1,000 and 6,000 did not solve it; neither did root walk or mixed starts or oracle balanced distance shells. The independent six-path audit corroborates exact probabilities at final checkpoints. Each run used 10,000 updates ×128 episodes ×8 slots, 10.24M padded slots. Reset distributions were precomputed from the finite shared transition graph; no online reset simulator calls were used. The graph/distribution computation is separate overhead.

These are informative negative controls alongside the CNOT success: plentiful local reward is not equivalent to reaching the full-task solution, and can even suppress rare paths. CNOT has many more shortest routes than these generalized-gate targets, despite an ordinary uniform hit probability lower than the three-wire target. This suggests path structure and transferable local skills matter, not just the base rate of terminal reward. The controlled comparison is within each task; differing gate families, input widths, horizons and topology prevent attribution of between-task differences to a single factor.

## Artifacts and reproduction

- `PLAN.md`: hypotheses and selection rules registered before each experiment; exact-ten CNOT candidate search failed at its cap, so the nine-step pilot was registered before training.
- `certificate.py`, `task.json`, `dag.json`, `train.py`, `runs/`, `audit.py`, `audit.json`: four-wire task and all 36 run records.
- `three.py`, `three_task.json`, `three_runs/`, `three_audit.json`: three-wire task and all 36 run records.
- `linear_certificate.py`, `linear_task.json`, `linear_dag.json`, `linear_train.py`, `linear_runs/`, `linear_audit.json`: five-wire CNOT task and all 12 run records.
- `audit_extra.py`: independent scalar verification and exact shortest-path probability calculations for CNOT and rare-three-wire tasks.

All runs were local Mac CPU, NumPy, no external models/checkpoints, no cluster allocations. Repository starting commit `9a484a84cb77e2018487c40e91cb4f6e9867371e`; working tree has concurrent research experiment additions. Each JSON run records weights, seed, mode, switch, counters, final test and elapsed time.

Reproduce the CNOT pilot from this directory:

```sh
python3 linear_certificate.py
for seed in 42 43 44 45; do
  OPENBLAS_NUM_THREADS=1 python3 linear_train.py --mode root --seed "$seed"
  OPENBLAS_NUM_THREADS=1 python3 linear_train.py --mode goal4 --seed "$seed"
  OPENBLAS_NUM_THREADS=1 python3 linear_train.py --mode goal4 --switch 1000 --seed "$seed"
done
python3 audit_extra.py
```

The supplementary audit script requires the saved rare-three-wire runs as well.

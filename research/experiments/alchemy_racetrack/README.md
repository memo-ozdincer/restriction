# Racetrack: beyond initial reward bootstrapping

Registered before code/rollouts. Hypothesis: exposure to native motion
states after an already competent common checkpoint permits learning
faster, reusable maneuvers than continued ordinary optimization. This is
a small original integer-grid vehicle environment, not a reproduction
of an existing game. Every state is position, velocity, remaining time
and fixed track geometry. Movement accelerates both axes by -1/0/+1,
caps velocity at three cells/frame, and checks a discretized line
segment against legal cells. On collision the vehicle stays in place
and stops; goal terminal is rightmost column. Exact deterministic
integer transitions; reward zero if no finish in 50 frames, otherwise
1+(50-finish clock)/50. No direction, collision, or maneuver rewards.

Tracks 24x15 have a vertical barrier at x=12 with a six-cell gap. Gap
starts sampled without score-based selection from 1..8; train on seed
20261127 split of four distinct gaps, held-out remaining four. State
features include gap location; no route supplied. Starting x=1,y=7,
velocity zero. Shared MLP stochastic evolutionary policy, top-four
parents, one elite, mutation sigma .15. Four independent paired seeds
42..45. Common ordinary training up to 300 generations, fork first
50-generation checkpoint with >=90% success on independent validation
noise on training geometry; report no qualifying fork if absent.
Terminal efficiency used from generation zero. Each arm 200 further
generations, last 100 all ordinary. Ordinary vs random reachable
prefix vs policy-generated reachable prefix (matched reset lengths).
Random starts generated by 1..8 native actions from root, no restart
at already terminal states, preserve elapsed clock and velocity.
Policy prefixes use common checkpoint controller (not an oracle).
Prefix generation occupies episode slots and is charged to all arms
by accounting total primitive transitions; use same 50 slots per
complete path, padded after finish. Prefix generation shared across
population in reset arms is not charged as free: report physical
prefix transitions both actual and per-candidate conceptual costs.
All policies train on identical maps, evaluate from official entrance
on unseen maps/noise. 24 candidates and 12 episodes per generation.
Predeclared outcomes: success, mean terminal efficiency, conditional
finish time; exact trajectory diagnostics: number of barrier crossings,
speed at first crossing, collision count, signed lateral motion and
route traces for inspection. If no stable improved held-out performance
or all differences explained by common strategy speed, no evidence of
new reusable maneuver. No demonstration of impossibility under all RL.
